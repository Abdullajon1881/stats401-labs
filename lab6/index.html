Design Description

Rectangle area encodes GDP because a treemap preserves the part-to-whole relationship: each country contributes to its area, continent, and the world total. Color is reserved for GDP status, using green for Increase, gray for Unchanged, and red for Decrease so the same categories can be scanned in either layout. Nested placement communicates the World-to-continent-to-area-to-country structure. Strong continent outlines and headers establish the largest groups, while lighter area outlines and smaller labels show the next level. Country names appear only when their rectangles have enough room, with the tooltip providing every exact value and ancestor. The Squarify layout produces more compact, square-like country shapes, which usually makes labels and area comparisons easier. Slice-Dice alternates its partition direction at each depth, so the recursive grouping is more visible as bands, but some countries become long, narrow rectangles. Neither method is always better: together they show how changing only the segmentation algorithm affects readability while every value, color, order, and tooltip stays fixed.

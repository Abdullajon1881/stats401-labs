The cleaning and analysis script is clean_tweets.py.

Note: the sentiment values shown here are estimates produced by a machine learning model, not ground-truth labels. The tweets were never labelled for sentiment by a person, so the model can be wrong on individual tweets.

Analysis

This page uses the CC0 “Disaster Tweets” dataset published by Viktor Stepanenko on Kaggle, which holds 11,370 tweets collected in January 2020. I took a deterministic random sample of 1,500 tweets and kept only the id, keyword, text and target columns; the location field was left out because this question does not need it. Cleaning was fairly light because the data was already tidy: I decoded percent-encoded keywords such as airplane%20accident into readable text (217 rows), dropped one tweet whose text exactly duplicated another, and checked for blank text, duplicate ids and invalid target values, of which there were none. That left 1,499 tweets. Sentiment was then estimated for every tweet with cardiffnlp/twitter-roberta-base-sentiment-latest. The chart puts tweet class on the x-axis, segment height as the share of tweets, and colour as the predicted sentiment. Disaster-related tweets came out more negative (51.5% against 42.2%) and much less positive (3.4% against 14.4%) than non-disaster tweets.

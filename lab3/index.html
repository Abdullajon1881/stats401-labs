STATS 401: Data Acquisition and Visualization

Bird occurrence records collected from a public API with Python, shown in a sortable table.

Dataset: Bird (class Aves) occurrence records

Source: GBIF Occurrence Search API

Method: REST API requests from Python using requests, looping over year and month slices with offset pagination

Records collected: 1224

The API needs no key or login, and GBIF's robots.txt allows this endpoint. Requests were sent one per second with a User-Agent identifying the class exercise. The acquisition script is acquire_data.py.
